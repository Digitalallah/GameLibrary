# GameLibrary

Личная библиотека игр с серверным хранением, синхронизацией со Steam и доступом по паролю.

## Что изменено

- Единственный рабочий источник данных — `data/library.json`; `games.json` используется только для первого запуска и восстановления.
- Список Steam обновляется через `IPlayerService/GetOwnedGames`.
- Поле «Реальный выход» означает первоначальный публичный релиз игры, а не дату появления страницы или издания в Steam.
- Дата Steam Store больше нигде не используется как дата выхода.
- На старте, при импорте, восстановлении и Steam-синхронизации приложение пересчитывает даты по Wikidata и `release-overrides.json`.
- Неподтверждённые старые и Steam-даты удаляются. Если надёжной даты нет, поле остаётся пустым.
- Отдельного столбца раннего доступа нет. Текущий ранний доступ обозначается меткой `EA`; по наведению или фокусу показывается ожидаемый полный релиз.
- Экспорт, импорт, CSV и восстановление спрятаны в меню «Управление данными».
- Все записи хранятся на сервере с атомарной записью и десятью резервными копиями.
- Добавлены строгая нормализация импорта, защита от XSS/CSRF, CSP, безопасный CSV и обработка повреждённых дат.
- При первом запуске сайт предлагает перенести прежние данные из `localStorage`, чтобы сохранить статусы и ручные правки.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
cp .env.example .env
set -a
. ./.env
set +a
node server.js
```

Откройте `http://127.0.0.1:3210` и введите `APP_USERNAME` / `APP_PASSWORD`.

## Steam-синхронизация

1. Получите Steam Web API key в настройках Steam Web API.
2. Укажите числовой SteamID64 в `STEAM_ID`.
3. Убедитесь, что сведения об играх профиля доступны API.
4. Нажмите «Синхронизировать Steam».

Синхронизация заменяет только Steam-часть библиотеки. Игры без `steamAppId`, добавленные вручную, сохраняются. Пользовательские статусы также сохраняются.

### Как выбирается дата

Приоритет источников:

1. Дата, которую пользователь исправил вручную в интерфейсе.
2. Исправление из `release-overrides.json`.
3. Самая ранняя дата публикации Wikidata для соответствующего Steam App ID.
4. Ранее подтверждённая дата из Wikidata или файла исправлений.
5. Пустое поле, если подтверждения нет.

Дата выпуска в Steam Store в эту цепочку не входит.

Пример: для Steam App ID `38410` хранится `1998-10-29` — первоначальный релиз Fallout 2, а не дата появления игры в Steam в 2009 году.

### Ручные исправления дат и раннего доступа

```json
{
  "123456": {
    "releaseDate": "2024-03-15",
    "isEarlyAccess": true,
    "expectedFullReleaseDate": "2027-01-01",
    "expectedFullReleaseText": "Разработчики ориентируются на 2027 год"
  }
}
```

Когда точная дата выхода из раннего доступа неизвестна, подсказка показывает «Дата полного релиза не объявлена».

## Развёртывание на Ubuntu

```bash
node --version  # должно быть v20 или новее
sudo apt install rsync caddy
sudo bash deploy/install.sh
sudo nano /etc/gamelibrary.env
sudo systemctl start gamelibrary
sudo systemctl status gamelibrary
```

Скопируйте `deploy/Caddyfile.example` в `/etc/caddy/Caddyfile`, замените домен и выполните:

```bash
sudo systemctl reload caddy
```

Приложение слушает только `127.0.0.1`; извне оно доступно через HTTPS-прокси Caddy. Само приложение дополнительно требует HTTP Basic Auth. Не публикуйте `APP_PASSWORD` и `STEAM_API_KEY` в GitHub.
